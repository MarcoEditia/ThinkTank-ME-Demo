# Evidence research

Search six evidence classes:
- current event status;
- official primary sources;
- evidence supporting the target outcome;
- evidence opposing the target outcome;
- historical reference cases and base rates;
- leading indicators and necessary conditions.

Prefer official documents and original reporting. Fetch important pages rather
than relying only on search snippets. Treat ten stories quoting one announcement
as one underlying evidence source. Preserve URLs and publication dates.
