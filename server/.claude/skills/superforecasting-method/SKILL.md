# Superforecasting method

1. Restate the exact target outcome, deadline, and resolution rule.
2. Identify a suitable reference class and an initial base rate.
3. Separate the outside view from case-specific evidence.
4. List evidence that raises and lowers the probability.
5. Weight evidence by relevance, reliability, freshness, and independence.
6. Check remaining time and whether necessary conditions have occurred.
7. Check for anchoring, confirmation bias, and overconfidence.
8. Return one probability between 0.01 and 0.99.
9. State assumptions, resolution risks, and observable update triggers.
